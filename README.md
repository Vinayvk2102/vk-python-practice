# VK Python Workbench

A collection of Python implementations developed through structured learning and independent problem solving. This repository documents **working examples and iterative improvements**, not production-deployed software.

## Explore the code

| Area | Content |
| --- | --- |
| [Fundamentals](src/fundamentals/) | Data types, variables, type conversion, console interactions |
| [Decision systems](src/decision_systems/) | Rule-based conditions, validation and decision scenarios |
| [Numerical utilities](src/numerical_utilities/) | Functions, calculations and numeric logic |
| [Business operations](src/business_operations/) | Pay, delivery cost and fare calculations |

## Selected implementations

- [Overtime pay calculation](src/business_operations/Funct_PEx5_OTGrosspay.py)
- [Delivery shipping calculation](src/business_operations/Funct_PEx8_DelShipcost.py)
- [Leap year determination](src/numerical_utilities/Funct_PEx9_Leapyear.py)
- [Rule-based vehicle speed monitoring](src/decision_systems/PractEx9_ifstatementProb5.py)

## Run locally

Requires Python 3. No external dependency is specified for the current standalone scripts.

```bash
python src/business_operations/Funct_PEx5_OTGrosspay.py
```

Scripts were originally created as part of a Python learning journey. Some files present instructional-style prompts or print demonstrations directly; they have not all been independently regression-tested or converted into reusable packages. The structure keeps the original filenames and source content intact.

## Development approach

Enhancements are intended to be incremental: demonstrate understanding, add relevant input validation, separate demonstration code from functions, and write tests before presenting a component as robust. Educational work is not described as commercial deployment.
